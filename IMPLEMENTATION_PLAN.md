# План реализации уведомлений и запуска Племенных книг

Дата: 14.11.2026. Приоритет — критичность и сохранность локальных данных. Кошки 0.8.16, собаки 0.2.8. Изменения объединять в пакеты, не плодить версии по одному пикселю.

## Пакет 1 — критично: аналитика и согласие
- [ ] В обеих книгах Яндекс Метрика не загружается до явного разрешения пользователя; без выбора и при отказе — никаких запросов к tag.js или информеру.
- [ ] Одна ненавязчивая плашка с выбором «Разрешить статистику» / «Без статистики» и ссылкой на политику; отказ не ограничивает функции.
- [ ] В «Настройках» доступно изменение решения. Отзыв должен прекращать дальнейший сбор; после отзыва исключить повторную загрузку информера. Если скрипт уже загружен, для полной остановки предложить перезапустить приложение.
- [ ] Проверить отсутствие запросов к Метрике при первом запуске, отказе, офлайн-режиме; согласие и повторный запуск; отзыв и перезапуск; браузер/Android/iOS PWA.

- [x] Импорт JSON: уже есть подтверждение с количеством записей до/после; не дублировать.
- [x] Окончательное удаление карточки: уже есть подтверждение вводом клички; не дублировать.
- [x] Перемещение в корзину: уже есть подтверждение; не дублировать.
- [ ] Достижение бесплатного лимита 20 карточек / 4 помётов: объяснить ограничение и сохранность ранее внесённых данных, без обещаний о неготовой оплате.
- [ ] Регрессия: карточки, помёты, импорт/экспорт, IndexedDB, установка, офлайн, обновление кеша.
