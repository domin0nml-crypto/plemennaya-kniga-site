## 2. Этапы и чеклист

### P0 — дожать первичную индексацию

- [x] Добавить и подтвердить сайт в Яндекс Вебмастере.
- [x] Добавить и подтвердить сайт в Google Search Console.
- [x] Отправить в Google `sitemap.xml`, подтвердить «Успешно» и 11 обнаруженных URL.
- [x] Проверить в Google Live URL главную, cats.html и dogs.html; запросить индексирование.
- [x] Импортировать сайт в Bing Webmaster Tools; убедиться, что sitemap.xml появился со статусом Processing.
- [x] Проверить Live URL в Bing для главной, устранить два замечания по метаданным, получить «No SEO/GEO issues found».
- [ ] **Bing:** выполнить Live URL для `https://breedbook.ru/cats.html` и `https://breedbook.ru/dogs.html`; исправлять только найденные проблемы.
- [ ] **Bing:** если главная ещё не отправлена через Request indexing — запросить один раз. Не отправлять повторно без причины.
- [ ] **Bing:** проверить, что Sitemap вышел из Processing; зафиксировать количество обработанных URL и состояние Bing Index.
- [ ] **Google:** 24.11.2026 проверить фактическую индексацию главной, кошачьей и собачьей страниц (не путать Live URL с индексом).
- [ ] **Яндекс:** после восстановления инструментов проверить страницы и индексацию; в robots.txt Sitemap уже объявлен, поэтому сайт может обнаруживаться без ручной подачи.
- [ ] Если к 01.12.2026 страниц всё ещё нет в индексе, расследовать именно указанную поисковиком причину; проверить ответы сервера, TLS, каноникализацию, доступность и качество контента.
- [ ] При повторении `ERR_SSL_PROTOCOL_ERROR` провести отдельную диагностику DNS A/AAAA, TLS, браузера/сети; не удалять Custom domain без причины. [Задача SSL](https://github.com/domin0nml-crypto/plemennaya-kniga-site/issues/3).

### P1 — бесплатная видимость и полезный контент

- [ ] Уточнить короткий список запросов по намерению заводчика, а не по абстрактным частотным словам:
  - главная — «программа для питомника кошек и собак», «электронная племенная книга»;
  - cats.html — «учёт вязок и помётов кошек», «племенная книга для кошек»;
  - dogs.html — «учёт помётов и щенков», «программа для собачьего питомника»;
  - инструкции — «как установить программу питомника», «как перенести базу питомника на другой телефон».
- [ ] Проверить, что каждое ключевое слово естественно соответствует содержанию страницы; не делать генеративные дубли и не злоупотреблять повторениями.
- [ ] Убедиться, что действующий URL `https://breedbook.ru/` размещён в профиле/закрепе ВК, описании Telegram-канала, его навигаторе и при выдаче ссылок ботом; где нет — обновить, не создавать новые страницы и посты без необходимости.
- [ ] Добавить реальные обезличенные примеры пользования книгою и качественные инструкции; публиковать отзывы только с разрешения автора.
- [ ] Проверить скорость мобильной загрузки и размеры изображений, не менять утверждённое оформление без причины.
- [ ] Не подключать метрику внутрь локальных книг ради SEO сайта; учитывать приватность и отдельное согласие для необязательной аналитики.

### P2 — измерение пользы, а не только индексации

Еженедельно в вебмастерах фиксировать по каждой системе:
1. страницы обнаружены → просканированы → проиндексированы;
2. реальные поисковые запросы, показы и клики;
3. ошибки сканирования, индексирования и причины исключения;
4. переходы с внешних площадок на сайт и открытия кошачьей/собачьей страниц по допустимой отдельно настроенной аналитике.

**Не считать «11 страниц обнаружено» равным «11 страниц в поиске».**

## 3. Следующее одно действие

**Bing → URL Inspection → Live URL → https://breedbook.ru/cats.html**. Зафиксировать «URL can be indexed» и замечания. Затем по тому же шаблону проверить dogs.html. Если нет блокирующих ошибок, возвращаться к содержательному продвижению и контролю индексации, а не повторять отправку Sitemap.
