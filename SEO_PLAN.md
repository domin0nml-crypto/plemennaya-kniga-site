### P1 — бесплатная видимость и полезный контент

19.11.2026 в ручной проверке Ларисы по запросу «племенная книга для кошек» страница `cats.html` заняла шестое место. По запросу «племенная книга для собак» на шестой странице выдачи появилась главная. Это исходные наблюдения до правок текста.

Рабочий словарь для трёх страниц. Варианты подобраны по возможностям книг. Частотность предстоит проверить в Яндекс Вордстате, а фактические показы сайта — в отчётах поисковиков.

| Страница | Как могут искать программу | Как могут искать решение задачи |
|---|---|---|
| Главная | программа для питомников кошек и собак, программа для заводчиков, электронная племенная книга, ежедневник заводчика | племенной учёт питомника, учёт животных и помётов на телефоне, ведение родословных офлайн |
| Для кошек | племенная книга для кошек, приложение для заводчиков кошек, программа для кошачьего питомника | журнал вязок кошек, учёт помётов котят, дневник веса котят, график роста котёнка, учёт окрасов WCF, календарь прививок котят |
| Для собак | племенная книга для собак, приложение для заводчиков собак, программа для собачьего питомника | журнал течек и вязок, учёт вязок и щенений, учёт помётов и веса щенков, график роста щенка, календарь прививок щенков, подготовка помёта к актировке |

#### Запросы для собачьего питомника

Первыми проверяем спрос на расчёт срока щенения и родства будущей пары. Для поиска родства используем термины «пробная вязка» и «коэффициент инбридинга». В собачьей книге окрас указывает заводчик. Запросы о генетическом прогнозе окрасов относятся к кошачьей странице.

| Задача | Варианты для проверки спроса | Что показать заводчику |
|---|---|---|
| Узнать, когда ждать щенков | калькулятор беременности собаки, рассчитать дату щенения по дате вязки, календарь беременности собаки по дате овуляции | В разделе «Вязки и беременности» вводятся даты вязок и отдельно известная дата овуляции. Книга показывает ориентировочный диапазон родов. |
| Оценить родство до вязки | пробная вязка собак по родословной, расчёт коэффициента инбридинга собак, как проверить родство кобеля и суки | В разделе «Родословные и родство» выбрать пару и посмотреть ожидаемый F потомства по внесённым предкам. Неполная родословная может занижать оценку. |
| Вести историю цикла | календарь течек суки, дневник течки собаки, как посчитать интервал между течками | Начало, окончание, наблюдения и интервал между началами внесённых течек. День овуляции программа из этих данных не вычисляет. |
| Вести помёт с рождения | дневник веса щенков, таблица взвешивания щенков, учёт бронирования щенков | Индивидуальные записи веса, график роста и статусы щенков в помёте. |
| Подготовиться к актировке | список щенков для актировки, учёт клейм и чипов щенков, распечатать сводку помёта | Внутренняя выписка по щенкам для сверки перед обследованием. Официальный акт оформляют отдельно. |
| Увидеть, что дала конкретная пара | учёт потомства племенного кобеля, история помётов суки, племенная сводка по производителям | В сводке выбрать животное или пару и посмотреть вязки, роды и потомство. |

### P2 — измерение пользы, а не только индексации

Еженедельно в вебмастерах фиксировать по каждой системе:
1. страницы обнаружены → просканированы → проиндексированы;
2. реальные поисковые запросы, показы и клики;
3. ошибки сканирования, индексирования и причины исключения;
4. переходы с внешних площадок на сайт и открытия кошачьей/собачьей страниц по допустимой отдельно настроенной аналитике.

**Не считать «11 страниц обнаружено» равным «11 страниц в поиске».**
